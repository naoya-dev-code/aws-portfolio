Architecture

GitHubへのpushをトリガーとして、GitHub ActionsからAWSへ 自動デプロイするCI/CD環境を構築しています。

Developer Git Push
→
GitHub Repository
→
GitHub Actions CI/CD
→
AWS IAM OIDC
→
Amazon S3 Static Website
→
CloudFront CDN / HTTPS
AWSアクセスキーをGitHubに保存せず、OIDCを利用してIAMロールを 一時的に引き受ける構成にしています。 デプロイ後はCloudFrontのInvalidationを自動実行し、 最新コンテンツを配信します。
